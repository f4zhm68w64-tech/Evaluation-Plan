# Evaluation Plan v1.0

Aplicación web/PWA local para crear y ejecutar evaluaciones multiple choice.

## Importación

Formato recomendado:

¿Qué orgánulo realiza principalmente la fotosíntesis?
A) Mitocondria
B) Cloroplasto
C) Ribosoma
D) Núcleo
CORRECTA: B
EXPLICACIÓN: La fotosíntesis ocurre principalmente en los cloroplastos.
TEMA: Fotosíntesis

Separar preguntas con una línea en blanco.

## Publicación
Subir estos archivos a la raíz del repositorio y activar GitHub Pages desde la rama `main`, carpeta `/ (root)`.

Los datos se almacenan localmente en el navegador mediante localStorage.
